Steam · Wallpaper Engine 创意工坊

先说清边界：Wallpaper Engine 没有对外开放的网页接口，工坊素材是 Steam 客户端内部文件， 任何网页都没法让你「登录后直接读到工坊库」—— 谁说能直连都是假的。但工坊里下载过的素材本质就是 视频 / 图片文件，按下面三步就能搬进来当开机背景，效果完全一样：

  1. 在 Steam 里打开 Wallpaper Engine 创意工坊，订阅并下载你喜欢的壁纸（视频类壁纸最好用）；
  2. 到本地文件夹 Steam\steamapps\workshop\content\431960\<工坊ID>\，里面就是壁纸本体（多为 .mp4 / .webm / .jpg / .png）；
  3. 把那个文件拖到本页「上传动效化」里，选好动效套到舞台 —— 工坊壁纸就变成你的 Muse / ChatGPT / Claude 开机片头了。

片头结构（三版通用）

0–1 秒黑场起尘、光扫过境；1–2 秒标志描边成形、品牌字逐字落下；2–5 秒两侧信息栏与终端 loading 同步滚动、进度条走满；5 秒光晕爆发是情绪高潮；6 秒口号定版、聊天框升起，表示“已就绪”。

三版的差别在哪

Muse 版用四角星火标 + 宝蓝，能力栏是 MEMORY / REASONING / CREATING / CODING， 口号走“灵感”路线；ChatGPT 版用六角结扣标 + 经典绿，能力栏和分析 / 思考 / 生成 / 解题对应， 口号就是原视频里那句 PROFESSIONAL WORK MODE；Claude 版用八向星芒标 + 陶土橙，能力栏是 THINKING / REASONING / CODING / WRITING，口号走“深度思考”路线。
