# AI 开机动画（AI Boot Animations）

**给 AI 助手的电影感开机 / 启动动画 —— Muse、ChatGPT、Claude 三个版本，一个零依赖的 HTML 文件全搞定。**

灵感来自 DeepSeek Harness 上爆火的开机动画插件。这个项目把那套 6 秒“操作系统开机”仪式，复刻给那些没有开放插件系统的 AI 助手：一道光扫过、标志描边成形、金属大字逐字显现、终端风 loading 日志、进度条走满、最后聊天框升起定版。

> **非官方粉丝概念作品。** 与 Meta、OpenAI、Anthropic 无关。所有标志均为手绘同风格图形，未使用任何官方素材。Muse、ChatGPT、Claude 都没有开放开机动画插件接口——这是一个可直接播放的概念演示，也是后续做启动器 / 桌面端集成的起点。

## 功能

- **三个品牌舞台** —— Muse（星火标、宝蓝、“灵感工作模式”）、ChatGPT（六角结扣标、经典绿、“专业工作模式”）、Claude（陶土橙放射星芒、“深度思考模式”），各自有能力栏和终端启动日志
- **黑客帝国矩阵雨模式** —— 全局开关（另有舞台特效选项和同名主题预设），三块屏幕同时下起片假名/数字雨，启动日志逐字打字输出
- **舞台特效** —— 故障 Glitch、粒子星尘汇聚、霓虹网格、光轨扫描、溶解收尾等
- **素材工作台**
  - 11 个代码生成主题（深海极光、霓虹雨夜、矩阵代码雨……），零素材也能玩
  - 在线搜图直连 **Wikimedia Commons**（默认）和 **Openverse**（备用），均免费、免 API key，点一张即套为开机背景
  - 更多免费素材网站目录（Pexels、Pixabay、Coverr、Mixkit、Videvo），如实标注哪些需要自己注册拿 key
  - **上传动效化**：拖入自己的图片或视频，选 10 种动效预设（缓慢推近、横向平移、呼吸律动、Glitch、星尘汇聚、霓虹、光轨扫描、溶解、VHS、静止）和时长，你的素材立刻变成开机动画；全程在本机内存处理，不经过任何服务器
  - **Steam Wallpaper Engine 导入**：粘贴工坊链接自动解析物品 ID，给出本地路径（`steamapps/workshop/content/431960/<ID>`）和 `steam://` 深链一键在 Steam 客户端打开，下载后把壁纸文件拖进上传区即可使用。（Wallpaper Engine 没有可直读工坊库的网页接口，本地导入是唯一真实可行的路线。）

## 为什么做这个

在 GitHub 上，开机动画插件只在平台开放可安装时才爆起来：DeepSeek Harness 有 20 多个这类仓库（原版一个月 300+ 星），ChatGPT/Codex 只有几个 0–1 星的尝试，Claude 只有三个小项目，Muse 一个都没有。这个仓库把这个概念收拢到一处，并保持它可魔改：单文件、代码可读、一切效果由代码生成。
